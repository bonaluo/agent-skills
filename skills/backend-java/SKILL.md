# backend-java

Spring Boot + Maven + MySQL + MyBatis Java 后端开发全栈技能。

## When to use

开发 Java 后端服务时使用，包括：
- 创建新的 Spring Boot 应用
- 开发 RESTful API
- 数据库 CRUD 操作
- 后端微服务开发

## 技术栈

| 组件 | 技术选型 |
|------|----------|
| 框架 | Spring Boot / Spring Cloud |
| 构建 | Maven |
| 数据库 | MySQL |
| ORM | MyBatis / MyBatis-Plus |
| Java | JDK 17+ |
